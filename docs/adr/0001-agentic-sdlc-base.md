# Agentic SDLC Base For Aura

Aura will use a lightweight, repo-native agentic SDLC instead of a heavy project-management system. The current maintainer is solo, so the workflow optimizes for fast context gathering, grilling unclear decisions, small specs, targeted implementation, verification, review, and durable documentation. The repo records always-on rules in `AGENTS.md`, navigation in `REPO_MAP.md`, process in `docs/agentic-sdlc.md`, durable decisions in `docs/adr/`, and repeatable procedures as skills.
