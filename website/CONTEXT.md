# Aura Wearable AI

Aura is an open-source AI wearable pendant that captures audio and images, processes them via AI models, and syncs memories to a mobile interface.

## Language

**Aura**:
The primary project name and the physical open-source AI wearable pendant device.
_Avoid_: Omi Glass, Optixel Cam, Optixel

**Omi**:
The third-party open-source ecosystem that powers Aura's backend and app integrations.
_Avoid_: Omi ecosystem

**Dilemma**:
The philosophical problem addressed by Aura, highlighting how smartphones and screen-based devices distract human attention.

**Docs**:
The instruction set and knowledge base for assembling the Aura hardware, uploading firmware, setting up the backend, and configuring the app.
