Build Your Own Aura

Everything you need to build an Aura pendant. Hardware files, firmware, and backend are all open source under MIT license.

Component Source Cost
XIAO ESP32-S3 Sense Seeed Studio / Amazon $15–24
OV2640 Camera Module Included with XIAO Sense —
MEMS Microphone Included with XIAO Sense —
150mAh LiPo × 6 Amazon $12
Wires & connectors Local electronics $5
3D printed case Print yourself or online $5–10
USB-C cable Anywhere —
Total — ~$50–70

1. Print the Case

STL files are in the hardware/ directory on GitHub.

Recommended: PLA, 0.2mm layer height, 15% infill.

View STL files on GitHub →

2. Flash the Firmware

Requires Arduino IDE 2.x with ESP32 board package version 2.9.0 (exact version).

Board: XIAO_ESP32S3
PSRAM: OPI PSRAM  ← required for camera
Upload Speed: 921600
View firmware on GitHub →

3. Run the Backend

Python 3.11+, FastAPI.

git clone https://github.com/thesohamdatta/aura
cd aura/backend
pip install -r requirements.txt
cp .env.example .env
# Edit .env: add your API keys
uvicorn main:app --reload
View backend on GitHub →

4. Configure API Keys

DEEPGRAM_API_KEY=your_key_here
GROQ_API_KEY=your_key_here
OPENAI_API_KEY=your_key_here  # for GPT-4o vision
PINECONE_API_KEY=your_key_here
PINECONE_ENV=your_environment

Deepgram free tier at console.deepgram.com. Groq free tier at console.groq.com.
