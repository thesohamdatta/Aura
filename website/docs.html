Getting Started

Aura is an open-source AI pendant built around the XIAO ESP32-S3 Sense. It uses a lightweight embedded C firmware to capture audio and images, streaming them over Bluetooth/WiFi to a companion app or directly to the backend.

Prerequisites

You will need a soldering iron, a 3D printer (or printing service), and basic knowledge of the Arduino IDE or PlatformIO.

Hardware & BOM

The total cost to build an Aura pendant is approximately $50 USD. Prices fluctuate based on supplier (AliExpress/Digikey).

Component Spec/Model Est. Cost
Microcontroller Seeed Studio XIAO ESP32-S3 Sense $14.99
Battery 3.7V 400mAh LiPo (502030) $4.00
Microphone INMP441 (I2S Interface) $2.50
Camera OV2640 (Included with XIAO Sense) $0.00
Enclosure 3D Printed Resin / PLA ~$3.00
Misc Wires, Kapton tape, Lanyard ring $5.00

Assembly

Assembly takes roughly 45 minutes for an experienced maker.

  1. Solder the Microphone: Connect the INMP441 VDD to 3.3V, GND to GND, L/R to GND, WS to GPIO 42, SCK to GPIO 41, and SD to GPIO 40.
  2. Attach Camera: Snap the OV2640 camera connector onto the XIAO board.
  3. Battery: Solder the battery wires to the battery pads on the back of the XIAO.
  4. Housing: Carefully insert the assembled unit into the 3D printed housing, ensuring the camera lens aligns with the front aperture.

Firmware

We use PlatformIO to manage the build process. The firmware handles I2S audio recording, JPEG compression for the camera, and BLE/WiFi networking.

Flashing the device


# Clone the repository
git clone https://github.com/thesohamdatta/aura.git

# Navigate to firmware
cd aura/firmware

# Build and flash via PlatformIO
pio run -t upload

Backend & AI Pipeline

The backend routes hardware streams through four major AI services.

  1. Deepgram: Real-time streaming transcription of the I2S audio feed.
  2. Groq: Llama-3 inference for sub-second intent classification and conversational responses.
  3. OpenAI: GPT-4o for processing the 1fps visual stream from the OV2640.
  4. Pinecone: Vector database for long-term memory retrieval based on transcript embeddings.
API Keys Required

You must copy `.env.example` to `.env` and fill in your keys for Deepgram, Groq, OpenAI, and Pinecone before starting the backend.

Mobile App

The companion app (React Native) is used for provisioning WiFi credentials to the pendant and acting as an alternative bridge when away from known WiFi networks.


cd app/
npm install
npx expo start

API Reference

The device communicates with the backend via WebSocket for real-time audio, and REST for settings.

WebSocket: Audio Stream

wss://api.aura.local/v1/stream

Expects raw 16kHz 16-bit PCM audio chunks.

REST: Memory Query

GET /v1/memory


// Request
{
  "query": "Where did I leave my keys?",
  "timeframe": "last_24_hours"
}

// Response
{
  "status": "success",
  "answer": "You left them on the kitchen counter at 8:45 AM.",
  "confidence": 0.92,
  "source_image_id": "img_993821"
}
