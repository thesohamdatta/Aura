Architecture

The AI Pipeline

Four layers. All cloud. All measured. Every number on this page is a median from our testing, not a marketing claim.

Aura's current pipeline is fully cloud-based. Voice goes to Deepgram. Images go to GPT-4o. Language reasoning runs on Groq. Memory is stored in Pinecone. A fully local option (Whisper + Ollama) is in development.

Speech-to-Text

Deepgram Nova-2

Converts voice to text in real time using Deepgram's Nova-2 model. Audio is captured at 16kHz mono PDM from the ESP32-S3's built-in microphone.

0.5s median latency
Cloud

Visual Understanding

GPT-4o

Processes images captured by the OV2640 camera. Describes scenes, reads text, identifies objects. SVGA (800×600) resolution is the operational sweet spot.

2.0s median latency
Cloud

Language Reasoning

Groq / Llama 3

Runs language inference at low latency using Groq's LPU hardware. Handles conversational context, summarization, and memory integration.

0.3s median latency
Cloud

Vector Memory / RAG

Pinecone

Stores conversation embeddings for retrieval-augmented generation. Aura can recall relevant context from past interactions to inform current responses.

RAG contextual retrieval
Cloud
