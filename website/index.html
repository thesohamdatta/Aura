Everything you wanted to know about Aura.

Read the Docs ›
mic

What does Aura actually capture?

Aura's 2MP wide-angle camera and dual MEMS microphones capture your conversations, environment, and visual context continuously — processing everything on-device with no raw data ever leaving your pocket.

security

Is my data private?

Everything is processed locally on the XIAO ESP32-S3. Audio is transcribed on-device via Whisper. Only anonymised semantic embeddings sync to the cloud. Your raw conversations are never uploaded or stored.

bolt

How fast does it respond?

Aura achieves sub-200ms response latency for context retrieval. Queries are processed via a RAG pipeline combining Pinecone vector search and Redis caching — designed to feel instant.

code

Can I build one myself?

Yes. Aura is fully open-source. The hardware BOM costs ~$50, firmware runs on FreeRTOS, and the full build guide is in the Docs. No soldering experience required for the base build.

smartphone

What phone does it work with?

Aura pairs with the companion Flutter app on both iOS and Android. The app handles voice queries, memory browsing, and settings sync via BLE. No proprietary ecosystem required.

battery_charging_full

How long does the battery last?

Aura runs all day on a single charge — designed for 8+ hours of active use. It charges via USB-C in under 45 minutes and enters a low-power standby mode when not actively capturing.
